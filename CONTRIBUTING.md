# Contributing

Thanks for helping improve Yopomura.

- Read the [contribution guide](docs/contribute.md).
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
- Check the [build guide](docs/build.md).
- Keep public builds free of site-specific extractors and adult site presets;
  run `pnpm check:content` before opening a pull request.
- Report security issues privately via [SECURITY.md](SECURITY.md), not a public
  issue.

Use conventional commit messages. Do not bump the version in a pull request.
